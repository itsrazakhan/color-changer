# 🎨 Color Changer

A simple webpage that changes the background color to a random color every time you click a button.

## 👀 Live Demo
🔗 [View it here](https://itsrazakhan.github.io/color-changer/)

## 📸 Preview
Click the button → background changes to a random color.

## 📁 Files
- `index.html` — The page structure
- `style.css` — The styling
- `script.js` — The color-changing logic
- `README.md` — You're reading it!

## 🧠 What I Learned
- Selecting elements with `document.getElementById()`
- Listening for clicks with `addEventListener()`
- Generating random numbers with `Math.random()`
- Converting numbers to hex colors with `.toString(16)`
- Padding strings with `.padStart()`
- Changing styles with `document.body.style`

## 🚀 How to Run
1. Download or clone this repo
2. Open `index.html` in any browser
3. Click the button and enjoy! 🎉

## 🔧 How It Works
1. A button is displayed on the page
2. When clicked, JavaScript generates a random hex color (like `#a3f2c1`)
3. The background of the page updates instantly
